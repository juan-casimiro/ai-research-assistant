# Evaluated envelopes before descriptive review corrections

These byte-identical copies preserve the manifest, conditions and post-annotation
query envelope used by the published diabetes reviewed results and the original
cardiology regression results. The earlier pre-category/reference diabetes
envelope remains in `../initial-authoring/`. Original result and receipt files
are unchanged; the current authoring release has later descriptive corrections
and different metadata fingerprints. See `../../review_corrections.json`.

This is an envelope snapshot for the existing runner/rescore helper, not a second
metadata archive or source corpus. Source PDF/text/XML files remain local in
`corpus/diabetes-v1`; raw metadata archives are in `../../metadata/`. No models,
retrieval, ingestion or paid calls were run to create this snapshot.
